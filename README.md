# Auto Deafen
A simple geode mod that auto triggers a hotkey at a certain per-level percentage to deafen you on discord.

## Quick Note:
This mod idea was originally from a developer known as "lynxdeer", however in private dms they said that they no longer have motivation and want to work on their mod anymore. I asked them whether I could create my own version of the mod from scratch, and he responded with yes, so here's the finished mod.

### How to Setup:
Go into your discord user settings, find "system", find "custom keybinds" and then add a keybind for deafening. Then, in the settings of this mod, set the deafen keybind to the same one you set in discord. It also will only work with 1 key, not more than 1.

### Also, just as a note, here are all the keys it works with:
1. All Function (F) Keys
2. All Numbers Keys
3. All Single Letter Keys
4. All Modifier Keys (ex. Insert, PageUp)
#### Any other keys not listed are most likely not compatible
